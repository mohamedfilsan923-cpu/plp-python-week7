# Week 7 Assignment: My Notes & The Report Builder

## Repository Files
- `my_notes.py`: Writes, appends, reads, and counts lines in a text file.
- `my_notes.txt`: Text file generated by `my_notes.py` containing four saved notes.
- `hubs.csv`: Input dataset containing learner names, hubs, and scores.
- `report_builder.py`: Reads `hubs.csv`, handles missing-file errors, and generates `report.txt`.
- `report.txt`: Summary report showing total learners, passed/failed counts, and average score.

## What Would Happen If `"a"` Were Changed to `"w"` in Question 1?
Changing `"a"` (append mode) to `"w"` (write mode) when adding the fourth note would erase and overwrite the first three notes in `my_notes.txt`. As a result, `my_notes.txt` would only contain `"I added this later"` and the total line count would be 1 instead of 4.
